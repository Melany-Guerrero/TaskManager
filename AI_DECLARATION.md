Declaración de uso de Inteligencia Artificial

Proyecto: TaskManager

Durante el desarrollo de TaskManager se utilizó una herramienta de inteligencia artificial como apoyo para comprender los requisitos del proyecto, organizar la estructura de los archivos, proponer estilos visuales y orientar la implementación de funcionalidades en JavaScript Vanilla (ES6+).

La herramienta también se utilizó como apoyo para comprender conceptos como la manipulación del DOM, los eventos personalizados (Custom Events), el consumo de API mediante Fetch y la persistencia de información utilizando localStorage.

El uso de inteligencia artificial tuvo como objetivo facilitar el aprendizaje y apoyar el proceso de desarrollo. La aplicación fue construida y organizada dentro de un repositorio personal de GitHub.

La responsabilidad de revisar, probar y comprender el funcionamiento del código corresponde al estudiante, quien debe verificar que las funcionalidades cumplan con los requisitos establecidos para el proyecto.

Esta declaración se presenta con el propósito de transparentar el uso de herramientas de inteligencia artificial durante el proceso de desarrollo académico.
